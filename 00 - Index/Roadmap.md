# Roadmap

The order to learn and build in for a shonen battlegrounds game. Each phase ends with something you can put in Studio and judge.

## Phase 1: Look target (1 week)
- [ ] Read [[Shonen Anime Shape Language]] and the battlegrounds visual analysis in `01 - Style Foundations`.
- [ ] Build a PureRef board: 3 characters, 1 arena, 5 abilities you want to match.
- [ ] Set up [[Lighting for Anime Maps]] in an empty baseplate and save it as a preset.

## Phase 2: One character, fully playable (2–3 weeks)
- [ ] Model one hero by following [[Anime Character Modeling in Blender]].
- [ ] Rig and export it: [[Roblox Character Rigs R6 vs R15 vs Custom]], [[Blender to Roblox Studio Export Pipeline]].
- [ ] Texture it flat and cel-shaded: [[Texturing Anime Characters]], [[Toon Shading on Roblox]].

## Phase 3: One move set (2 weeks)
- [ ] 4-hit M1 combo, dash and block, following [[Anime Combat Animation Timing]].
- [ ] VFX for each hit, following [[Anime VFX Fundamentals]].
- [ ] Hitstop, screen shake and impact frames.

## Phase 4: One arena (2 weeks)
- [ ] Modular kit and stylized nature: [[Stylized Environment Kits]].
- [ ] Destruction and craters, then a mobile performance pass.

## Phase 5: Ultimate sequence (1–2 weeks)
- [ ] One awakening/ultimate with its own camera, VFX and sound.

## Phase 6: Scale up
- [ ] Commission extra characters: [[Commissioning and Briefing Artists]].
- [ ] Follow [[Top Roblox Modeler Workflow Patterns]] to keep quality consistent.
