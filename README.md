# Anime Roblox Style: Shonen Battlegrounds Art Bible

A research-backed knowledge base on **how to build shonen anime-style Roblox games** (the battlegrounds genre: The Strongest Battlegrounds, Jujutsu Shenanigans, Heroes Battlegrounds, Type Soul and similar). It covers how top Roblox modelers, VFX artists and animators actually make these games.

This repo is an **Obsidian vault**. Clone it, then open the folder in Obsidian with *Open folder as vault*. Notes link to each other with `[[wikilinks]]`, and every note cites its sources.

```bash
git clone https://github.com/yeahdudeingtonium/anime-roblox-style
```
